# ASL Fingerspelling Recognition System 

A Deep Learning Project for American Sign Language (ASL) Fingerspelling Recognition.

## 📌 About the Project

This project explores deep learning approaches for recognizing ASL fingerspelling sequences using machine learning and transformer-based architectures. It focuses on experimenting with hand-landmark data, sequence modeling, and text recognition techniques.

## 🎯 Objectives

- Explore preprocessing of ASL fingerspelling data.
- Experiment with BERT-based architectures.
- Investigate sequence recognition using Connectionist Temporal Classification (CTC).
- Study model training and evaluation for fingerspelling recognition.

## 🛠️ Technologies Used

- **Language:** Python
- **Environment:** Jupyter Notebook, Kaggle
- **Libraries:** NumPy, Pandas, Scikit-learn
- **Deep Learning:** BERT-based models, CTC
- **Data Processing:** Hand-landmark features

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/priyya16/ASL-Fingerspelling-Recognition.git
   ```

2. Open the project folder and launch Jupyter Notebook or upload the notebooks to Google Colab.

3. Obtain the required dataset from the [Kaggle ASL Fingerspelling Competition](https://www.kaggle.com/competitions/asl-fingerspelling).

4. Configure the dataset paths and install the dependencies required by the notebook you want to run.

5. Run the notebook cells in order.

## 📊 Dataset

The project uses data associated with the Kaggle ASL Fingerspelling Competition. Dataset access and usage are subject to Kaggle's rules and competition terms.
